# kouthoofdmartensson.com

Portfolio site. Plain HTML, no build step.

**To edit:** go to https://app.pagescms.org, sign in with GitHub, open this repository, and edit the *Portfolio* entry. Save, and Netlify republishes the site within a minute.

- `content/site.json` – all text, projects and image paths
- `images/` – photos
- `index.html` – layout and styling
- `.pages.yml` – settings for the Pages CMS editor
